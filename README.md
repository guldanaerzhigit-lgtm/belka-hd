# Belka HD

Мобильный веб-прототип карточной игры «Белка».

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Возможности прототипа
- Адаптивный интерфейс для телефона
- Колода из 32 карт и случайный козырь
- Выбор карты касанием и розыгрыш свайпом
- Сортировка карт по мастям
- Демонстрационные ходы соперников

**Важно:** это ранний прототип. Полные правила Белки, точный подсчёт очков и игровая логика ботов ещё требуют реализации.
